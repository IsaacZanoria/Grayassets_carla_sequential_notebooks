##### ISAAC'S NOTE FOR CARLA EXPERIMENTS ####################################################

When running the CARLA training code, first, run "conda activate IoBT-genesis" to get the environment up

In general (this holds for the straight line dataset so far) we train the Stage 1 (packet grouping model) on the seed2 dataset, using notebook 4

↪ After training on notebook 4, we use the completed model weights to predict the packet boundaries on seed1 (using notebook 4a), then use those predicted packet groups on the trajectory prediction task

The dataset directory (./grayassets_datasets/) structure is as follows:
```
↪ grayassets_datasets/

    ↪ separatevehicles_3types_3colors_onlyIPframes_720p_no_trafficlights_no_weather_more_redundancy/    # Level 1: The experiment type
        ↪ seed1/                # Level 2: the seed used to generate the experiment

            ↪ indexed_samples/       # NOTE: You don't have to generate this, this is populated by notebook 1. It's a good place to confirm the structure of the csv files being read in notebook 2.
                ↪ framesizes/
                ↪ packetsizes/
                ↪ trajectories/
                
            ↪ raw_files/             # IMPORTANT: THIS IS WHERE YOU PUT ALL THE DATASET FILES GENERATED BY GAOFENG. use the same directory structure I show here, or notebook 1 will not parse it correctly
                ↪ framesizes/
                    ↪ *sample 0 long name*
                    ↪ ...
                ↪ packetsizes/
                    ↪ bw10mbit_delay0_jitter0_loss0/
                        ↪ *sample 0 long name*
                        ↪ ...
                    ↪ bw10mbit_delay20_jitter5_loss0/
                    ↪ ...
                ↪ trajectories/
                                ↪ *sample 0 long name*
                    ↪ ...
            
            ↪ tensors/               # This will be created automatically by notebooks 1,2,3, and 4, but you need to know where this is so that you can load the right tensors in for the stage2 training
                ↪ packetsizes/
                    ↪ bw10mbit_delay0_jitter0_loss0/
                        ↪ packet_grouping_model_weights/            # (if it exists) trained stage 1 model weights for the indicated dataset
                        ↪ packet_grouping_training_tensors/         # The packetsize csv's loaded into tensor format for training stage 1

                        ↪ learned_grouping_output_log.txt           # Gives a train history and error rate for Stage 1
                        ↪ learned_grouping_tensor.pt                # The stage 1 - grouped tensor (analagous to the framesizes tensor). Non-normalized, good for direct comparison to framesizes tensor 
                        ↪ normalized_learned_grouping_tensor.pt     # The normalized stage 1 output tensor, this is what is passed to stage 2

                        ↪ windowed_packets_tensor.pt                # windowed packets tensor (naive grouping)
                        ↪ normalized_windowed_packets_tensor.pt     # normalized version that can be fed into stage 2

                    ↪ ...
                ↪ raw_files/
            
            ↪ results/
```
